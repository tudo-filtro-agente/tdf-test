# 05 — Respostas Rápidas WATI (Quebra de Objeção)

> **Origem:** condensado do arquivo `04-QUEBRA-DE-OBJECOES-TDF.md` em formato pronto pra cadastrar no painel WATI como "Resposta Rápida" (canned response).
> **Quem usa:** closers (Cátia, Larissa, Fabiana, Ítalo, Gabriel F., Pedro). Núbia já tem isso no prompt.
> **Como usar:** durante a conversa, digita o atalho (ex: `/tacaro`) → WATI cola a mensagem → editar nome do cliente → enviar.

---

## Como cadastrar no WATI

1. WATI dashboard → **Settings** → **Canned Responses** (ou "Respostas Rápidas")
2. **+ Add new response**
3. Title: o nome curto do atalho (ex: `tacaro_b2c`)
4. Message: copia o texto abaixo
5. Save

> **Importante:** sempre revise o nome do cliente antes de enviar (substitua `[Nome]`).

## 💰 Objeção: "TÁ CARO"

### `/tacaro_b2c` (residencial — Filtro Entrada / Iron Free / Refil / Bebedouro residencial)
```
[Nome], compreendo. Caro comparado a quê? Você teve outras propostas?
Se sim, posso te ajudar a comparar item por item — porque às vezes o que parece igual não é.
```

### `/tacaro_b2c_payback` (segunda tentativa B2C — payback)
```
[Nome], olha por outro ângulo: o sistema custa R$[X], dura em média [Y] anos = uma média de R$[X/(Y*12)] por mês.
Quanto você gasta hoje em [garrafão/troca de chuveiro/produto pra mancha]? Vamos colocar lado a lado.
```

### `/tacaro_b2c_inacao` (terceiro nível B2C — custo de não fazer)
```
[Nome], faz sentido pesar. Mas o problema da água [X] não vai embora sozinho.
Em 12 meses você vai ter gastado [Y] mil em consequências (chuveiros novos, roupa estragada, problema de pele) — e ainda continuar com o problema.
Esse investimento uma vez resolve. Como você quer fazer — à vista com [X]% de desconto ou parcelado?
```

### `/tacaro_b2b` (industrial / comercial / condomínio)
```
[Nome], compreendo. Caro comparado a quê — outra proposta, ao orçamento que você imaginava ou ao retorno esperado?
Pra eu te ajudar de verdade, preciso entender.
```

### `/tacaro_b2b_payback` (B2B com ROI)
```
[Nome], o investimento é R$[X]. Mas com [redução de manutenção / parada de produção / troca de equipamento] vocês economizam R$[Y] no ano 1.
Em [Z] meses o sistema se paga. Posso preparar essa planilha pra você apresentar pra diretoria?
```

### `/tacaro_b2b_pattern` (B2B firme — pattern de mercado)
```
[Nome], se a gente for pelo caminho do menor preço, vou te perder pra alguém que vende equipamento abaixo do necessário e em 12 meses você vai pagar de novo.
Já vi isso 4-5 vezes esse ano. Vamos pelo caminho certo da primeira vez?
```

## 🤔 Objeção: "VOU PENSAR / VOU TE RETORNAR"

### `/pensar`
```
[Nome], faz sentido. Pra você não ficar com dúvida pendente, posso te perguntar uma coisa: o que ainda tá em aberto pra você decidir?
Se for preço, prazo, dúvida técnica ou outra coisa — me conta que eu já te ajudo.
```

### `/pensar_compromisso`
```
[Nome], te entendo. Que tal a gente combinar assim: você dá uma pesada hoje à noite e amanhã às [10h ou 16h] eu te chamo pra alinhar — mesmo que seja pra você dizer "agora não".
Funciona pra você?
```

## 👥 Objeção: "VOU CONSULTAR MINHA ESPOSA / MARIDO"

### `/conjuge`
```
[Nome], faz total sentido. Decisão grande dentro de casa é decisão a dois.
Posso te ajudar a apresentar pra ela(e)? Posso preparar um áudio rápido de 2 minutos explicando os pontos principais — do jeito que ela(e) vai entender.
```

### `/conjuge_pontos`
```
[Nome], ótima atitude. Pra você não fazer essa apresentação no escuro, posso adiantar:
o que mais a [esposa/marido] valoriza — economia, conforto, saúde da família?
Assim eu te dou os 3 pontos que mais vão pesar pra ela(e).
```

### `/conjuge_call`
```
[Nome], que tal a gente fazer mais simples — uma rápida ligação com vocês dois, eu explico em 5 minutos e ela(e) já tira as dúvidas direto comigo?
Tenho horário [data 1] de noite ou [data 2] no almoço. O que encaixa?
```

## 🏢 Objeção: "PRECISO LEVAR PRO SÍNDICO / ASSEMBLEIA"

### `/assembleia`
```
[Nome], perfeito. Decisão de condomínio passa por eles mesmo — ótimo que você está sendo cuidadoso.
Pra você defender essa proposta com argumentos sólidos, posso preparar:
- 1 resumo executivo em 1 página
- planilha de payback (economia esperada)
- lista de condomínios parecidos que atendemos
Quer que eu monte?
```

### `/assembleia_visita`
```
[Nome], outra opção: posso ir junto na assembleia (presencial ou online) explicar pros condôminos.
Já fizemos isso em outros condomínios — costuma ajudar muito a aprovar de primeira.
Quando seria?
```

## 🔍 Objeção: "VOU PESQUISAR CONCORRENTES"

### `/pesquisar`
```
[Nome], faz sentido pesquisar — bom sinal de quem decide com cuidado.
Pra te ajudar a comparar com isenção, posso te mandar uma checklist de 5 itens que diferenciam um sistema bem-feito de um meia-boca?
Assim você compara orçamentos no mesmo critério.
```

### `/pesquisar_combinado`
```
[Nome], combina o seguinte com você: pesquisa 2-3 propostas, me manda os pontos das outras e eu te mostro lado a lado, item por item, sem floreio.
Geralmente o que parece "igual e mais barato" tem buraco que aparece depois. Topa?
```

## 💧 Objeção: "MINHA ÁGUA PARECE BOA, NÃO PRECISO DISSO"

### `/aguaboa`
```
[Nome], a maioria das águas que parecem boas no olho passam direto em parâmetros que só análise pega: dureza, ferro residual, cloro alto, microbiologia.
Posso te enviar um teste rápido de cloro residual que você mesmo faz aí em casa? Aí decidimos juntos se vale uma análise mais completa.
```

### `/aguaboa_indicios`
```
[Nome], te pergunto algumas coisas rápidas pra entender:
1) Você sente cheiro/gosto de cloro?
2) Tem mancha branca em torneira/box?
3) A roupa branca tá saindo amarelada?
Se a resposta for sim em qualquer uma, sua água tem ponto de melhoria — mesmo parecendo boa.
```

## 🛠️ Objeção: "JÁ TENHO FILTRO / SISTEMA INSTALADO"

### `/jatenho`
```
Que ótimo, [Nome]! Posso te perguntar 3 coisas pra entender se ele tá fazendo o serviço completo?
1) Modelo/marca?
2) Quando foi instalado?
3) Você já trocou os elementos filtrantes alguma vez?
Muitas vezes o sistema existe mas tá saturado — funciona pior que não ter filtro.
```

---

## 🛒 Objeção: "POSSO COMPRAR MAIS BARATO EM LOJA / MERCADO LIVRE"

### `/loja`
```
[Nome], dá sim pra comprar mais barato. Mas três pontos importantes:
1) Sem visita técnica, você corre risco de comprar dimensionado errado e gastar duas vezes
2) Sem laudo, não tem como saber se a mídia certa é a que a água pede
3) Sem pós-venda local, troca de elementos vira dor de cabeça
A gente entrega análise + dimensionamento + instalação + garantia — não é o mesmo produto.
```

## 🚗 Objeção: "NÃO SEI SE PRECISO DE VISITA TÉCNICA"

### `/visita`
```
[Nome], a visita técnica é parte do projeto e serve pra duas coisas:
1) Análise da sua água (saímos com amostra)
2) Avaliação de onde instalar o sistema (espaço, encanamento, energia)
Sem isso eu te dou uma proposta no chute — e ninguém quer isso. Ela já entra na proposta final. Posso agendar essa semana?
```

### `/visita_remoto` (cliente longe)
```
[Nome], a gente atende [Vale + RMVP + capital + ABC + Litoral Norte + 500km de SJC com taxa].
Pra sua região [cidade], a visita pode ser presencial ou via call com fotos+vídeo do local.
Qual prefere?
```

## 💳 Objeção: "PRECISO DE PRAZO DE PAGAMENTO"

### `/prazo`
```
[Nome], a gente tem várias formas:
1) PIX/boleto à vista (com desconto)
2) Cartão em até [X] vezes sem juros (depende do produto)
3) Boleto parcelado em até [Y] vezes (com juros baixos)
Qual cenário encaixa melhor pra você?
```

---

## 🧪 Objeção: "E SE NÃO FUNCIONAR?"

### `/funciona`
```
[Nome], pergunta válida. Funciona assim:
1) Antes da instalação, fazemos análise da sua água — se identificarmos que o sistema não vai resolver, te avisamos e nem instalamos
2) Após instalado, fazemos nova análise pra confirmar resultado
3) Garantia [X meses] do equipamento + suporte local
A gente trabalha pra você indicar pra próximo, não pra fechar uma vez e sumir.
```
